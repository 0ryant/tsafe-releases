tsafe apt repository

A signed third-party APT repository for tsafe, a local-first secrets runtime. This is not the official Ubuntu archive — you add it manually, the same way you would Docker's or Chrome's repo.

Install (Debian/Ubuntu, amd64)

sudo install -m0755 -d /etc/apt/keyrings
curl -fsSL https://0ryant.github.io/tsafe-releases/apt/tsafe-archive-keyring.gpg | sudo tee /etc/apt/keyrings/tsafe.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/tsafe.gpg] https://0ryant.github.io/tsafe-releases/apt stable main" | sudo tee /etc/apt/sources.list.d/tsafe.list >/dev/null
sudo apt update && sudo apt install tsafe

The repository Release is signed with a free OpenPGP key; the binaries themselves are unsigned. Other channels: cargo install tsafe-cli, Chocolatey (choco install tsafe), and Homebrew (in progress).

Source is private; compiled artifacts live at github.com/0ryant/tsafe-releases.
